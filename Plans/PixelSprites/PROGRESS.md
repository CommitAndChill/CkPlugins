## Design and validation decisions

- Independent CkPixelSprite module approved by bounded Astra source review. Existing CkPixelArt owns scene pixelation. Runtime uses CkModuleRules with unity disabled and a public CkCore dependency for FCk_Time. No editor dependencies.
- Maintainer ruling 2026-10-11: malformed XPM/JSON is an ordinary structured TryParse failure in every build; reserve CK ensures for programmer invariants at this parsing boundary. Do not change ensure macros or build flags.
- Native payloads are plain non-reflected value structs with _Members, not ECS fragments or imported assets. Parse/evaluation failures leave caller payload outputs unchanged. Diagnostic output deliberately changes on failure.
- Source review found and repaired quoted qualifier acceptance, custom-limit row-count overflow, small-duration modulo behavior, cumulative timing boundaries and nonfinite sampling. Native regression tests are authored, not yet executed.
- Python exports reject destinations aliasing sources, linked destinations and Windows junction paths; sprite-sheet output pairs stage and roll back failed publication. Python 3.12+ is required for junction inspection. No external dependencies.
- Optional layers and full X11 named-color support are explicitly rejected rather than approximated. The native API consumes decoded FString, not file bytes; importer must later enforce UTF-8 and byte bounds.
- Next native manifest slice: bounded Astra review recommends private Json dependency and validated JSON fragments for events/metadata, retaining nested types and numeric lexemes via StoreNumbersAsStrings (not claiming canonical ordering). Pure schema parsing precedes bounded file resolution; all outputs publish atomically after every dependency validates. Duplicate decoded keys, depth/node limits, exact integer-token schema fields, nonfinite floats and strict UTF-8 must be checked before admission. Maintainer explicitly selected native ordinary-file loading on 2026-10-11: reject symlinks/junctions, including links resolving inside the root. Document this as stricter than Python, and scope loading to a stable local authoring tree; no race-free hostile-filesystem confinement claim. Validate each existing traversal component including root, since IsSymlink can return NonSymlink on an attributes failure. GetFilenameOnDisk is not proof of containment.
